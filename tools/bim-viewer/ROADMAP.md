# Bright.Vision 查看器分阶段交付

按用户 2026-10-27 确认的“全部功能、分阶段交付”推进。VIM Flex 是设计参考，功能实现与证据见本项目源码和测试；没有把其闭源原生算法视作已完整恢复。

土建算量的完整功能另见 [Revit／查看器／云端算量六期计划](../bright-revit-exporter/CIVIL_QUANTITY_ROADMAP.md)。当前查看器原始量表是基础能力；本页的大模型、碰撞和版本审查不能代替土建规则及增扣计算。

| 阶段 | 范围 | 验收边界 |
|---|---|---|
| 第一阶段：浏览与交互 | 空间分区合批、重复几何实例化、层级/BVH拾取；索引筛选与虚拟构件树；多选、ghost隔离、剖切盒、两点测量、命名视点、类别/面数审查 | 类型/单元测试、真实 WebGL 场景、现有 ZIP 回归；不把机制变更描述为未经测量的提速比例 |
| 第一阶段：导出与安装 | 自研 Revit 2015–2026 API 变体、2025/2026双运行时、自动检测注册，输出米制 JSON ZIP | 逐年编译、格式夹具和隔离部署；逐年实机加载/导出仍需验收 |
| 第二阶段：大模型资源管理 | 首帧与属性/纹理解耦、按需查询与本地索引缓存、上传队列、显存预算、屏幕尺寸LOD、进一步评估Hi-Z/WebGPU | 固定设备/模型/相机记录首帧、峰值内存、帧时分位数、拾取耗时和资源回落；有低精几何才能声称真正LOD减面 |
| 第三阶段：工程审查 | 精确碰撞检查、净距规则、结果持久化；稳定身份与几何/参数版本比较；工程警告与参数质量审查 | AABB仅作候选；精确碰撞需几何验证，版本匹配需文档/构件稳定标识；源模型未提供的数据不能由界面补出 |

第一阶段不包含完整 GPU Hi-Z、显存流送、自动低精网格生成、精确碰撞或模型版本对比。后续阶段以这些明确能力为交付目标，不用占位按钮代替实现。

所有阶段保留本地处理、独立查看器不启动 Revit、模型导出由用户在 Revit 插件中执行的边界。旧模型包没有单位声明时显示“模型单位”或由用户指定，不能自动认定为米。
