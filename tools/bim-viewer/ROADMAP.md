# Bright Vision 查看器分期计划

当前查看器源码为 **0.7.0 开发预览**，插件仍为 **BV 1.7.0**。本页区分已经实现的基础能力与后续范围；发布、实测设备与支持边界以对应 Release 和验收记录为准，不用路线图替代已交付功能。

## 已有基础能力

| 范围 | 当前实现 | 验收边界 |
|---|---|---|
| 浏览与交互 | 空间分区合批、重复几何实例化、层级／BVH 拾取；Worker 索引筛选与虚拟构件树；多选、隐藏、隔离、剖切盒、两点测量、命名视点、类别／面数审查 | 单元／类型检查与合成模型 WebGL 场景；不声称未经固定设备与模型测量的提速比例 |
| 导出与安装 | 独立 Revit 2015–2026 API 变体、2025／2026 双运行时、自动检测与注册、米制 JSON ZIP、原始量快照 | 共 14 个年份／运行时编译目标；真实宿主验证只覆盖已单独记录的 build 和算例，不能推及所有年份 |
| 0.7 人物漫游与飞行 | 可见人形与第三人称跟随视角、手动地面起点、基础地面采样和射线阻挡、自由飞行、速度／眼高与明确单位 | 本轮只做 CLI／独立 headless 浏览器；不是完整人体碰撞、复杂楼梯通行、自动寻路或疏散分析 |
| 0.7 本地模型助手 | 确定性规则查询模型概览、类别、楼层、所选属性、缺失字段、原始量；明确语法查找、缺少参数检查及构件定位依据 | 本地执行，不是大语言模型，不请求云端 AI；不理解任意自然语言条件、不判断规范合规、不计算地区扣减 |

查询语法和统计口径见 [README](README.md)。0.7.0 本轮不启动原生 Electron 窗口或真实 Revit；后台测试只使用内置合成演示模型及脚本生成的安全 ZIP。[实际 CI](https://github.com/queqideliang/bright-vision/actions/runs/40710215364) 已在固定 Linux runner 的系统 Chrome 中通过 14 项 headless 场景，保留沙箱。入口与证据边界见 [BACKGROUND_TESTING.md](BACKGROUND_TESTING.md)。

## 后续交付方向

| 阶段 | 范围 | 完成时需要的证据 |
|---|---|---|
| 导航完善 | 身体体积碰撞、相机遮挡处理、复杂台阶／坡道与狭缝、合理降级提示 | 固定尺寸合成关卡与真实工程样本，覆盖薄墙、低矮障碍、楼梯、悬空和单位转换；自动寻路需另外定义可通行图及路径正确性 |
| 本地模型审查 | 可配置参数检查、结果保存、来源追溯与稳定构件身份 | 明确规则与不支持项、正反例、重复来源和缺失数据测试；结果能回到具体构件和原始属性 |
| 可选模型 AI | 在独立设计与授权后评估本地或托管模型接口、受约束查询与证据引用 | 先定义数据范围、费用、授权及错误处理；默认本地规则版不会因此自动上传数据，AI 答案不得替代可复核的计量算法 |
| 大模型资源管理 | 首帧与属性／纹理解耦、按需查询与本地索引缓存、显存预算、屏幕尺寸 LOD，评估 Hi-Z／WebGPU | 固定设备、模型、相机，记录首帧、峰值内存、帧时分位数、拾取与资源回落；有低精几何才能宣称 LOD 减面 |
| 工程审查与版本比较 | 精确碰撞、净距规则、结果持久化；稳定身份与几何／参数差异 | AABB 仅作候选，精确碰撞需几何验证；版本匹配需源文档／构件稳定标识，源模型未提供的数据不由界面补出 |

土建规则、增扣和计算书的独立分期见 [土建算量计划](../bright-revit-exporter/CIVIL_QUANTITY_ROADMAP.md)。查看器导航、统计或助手不等同于完整土建算量；云端重算和专业服务不在当前社区版功能中。

所有阶段保留独立查看器不启动 Revit、用户在 Revit 插件中执行模型导出的边界。旧包没有单位声明时显示“模型单位”或由用户明确指定，不按外观猜测为米。完整 GPU Hi-Z、显存流送、自动低精网格、精确碰撞、自动寻路与模型版本对比均未作为当前已交付功能。
