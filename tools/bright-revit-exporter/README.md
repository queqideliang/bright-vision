### 为什么测试时会看到多个加载确认

正式插件与临时 SDK 验收插件是不同的加载入口，截图中名称含 `SDK acceptance` 的是测试工具。验收结束后临时注册会按准确路径和哈希清理，正式安装包也不包含 SDK 验收 DLL。兼容旧安装的同名注册覆盖用于阻止旧导出器加载，不应当直接删除，否则可能重新启用旧插件。

专用 SDK 测试现在通过 CLI 启动、运行并清理，结束前核对运行身份、进程创建时间、模型标题、回滚及源文件哈希，不要求用户反复开关测试样例。发布者安全提示仍由用户核对处理。当前安装包与插件 DLL 为 `NotSigned`；后续发行应补发布者代码签名。受信任的同一证书／发布者可减少重复提示，具体信任决定由用户确认，见 [Autodesk Revit 2020 签名说明](https://help.autodesk.com/cloudhelp/2020/ENU/Revit-Troubleshooting/files/GUID-900A3EBF-A809-4A0E-96ED-5EEC965A2728.htm)。

当前开发包未配置 Authenticode 公司签名。`Load Once` 仅允许本次加载；信任选择应由用户核对 DLL 路径后自行作出。已变更的程序集或测试路径仍可能再次提示。正式发行应使用受信任机构颁发的公司代码签名证书，签署实际插件和安装器；文件 SHA-256 不能替代发布者签名。参见 [Autodesk 的加载选项说明](https://help.autodesk.com/cloudhelp/2020/ENU/Revit-Troubleshooting/files/GUID-36D29367-A540-4CFD-9773-4995BF1DF08A.htm)及[开发者签名说明](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API/files/Revit_API_Developers_Guide/Introduction/Add_In_Integration/Revit_API_Revit_API_Developers_Guide_Introduction_Add_In_Integration_Digitally_Signing_Your_Revit_Add_in_html.html)。

## 在 Revit 中使用

通过 [独立安装器](../bright-revit-installer/README.md) 安装，保存工程并退出全部 Revit 后升级，重新启动生效。入口为 **BV → bright vision**，官方产品显示“崛亮视觉 · Bright Vision”。

- **本地导出模型 ZIP：** 编辑模型名、选择非模板三维视图、输出目录和导出内容。已有 ZIP 覆盖须确认；失败或取消不替换原包。完成后显示输出统计、耗时、源 RVT 和 ZIP 大小及体积变化。
- **土建原始量工作台：** 在 Revit 内按范围、类别、阶段／设计选项读取原生参数，筛选分组、定位构件和输出 CSV，无须先导出 ZIP。
- **工程设置：** 计量层映射、单一施工段归属和 `.bvproject.json` 存取，保留原楼层与解析来源；只改变报表归属，不切分几何或写回 RVT。
- **墙体试算与台账：** 普通直墙事实、几何核对、矩形开洞并集扣体积与 CSV；1.8 增加单侧轴向投影面积、工程归属分组、覆盖状态及新版报表。未支持或失败记录单列，不按零补齐。

接收者安装 [独立查看器](../bim-viewer/README.md) 后，无需安装 Revit 即可打开导出的 ZIP。查看器不能直接读取 RVT；插件本身必须在合法 Revit 宿主内执行。

## 原始量与工程设置

墙、结构梁、建筑柱、结构柱、板分别读取固定实例参数中的长度／面积／体积，保留参数来源、单位和状态。结构支撑不当梁；叠层墙、幕墙、嵌套族、未映射和未加载链接等保留明确覆盖与排除信息，不混入受支持合计。

当前选择／当前视图／当前工程首先限定根文档。阶段与设计选项明确显示；视图纳入构件时仍读取整构件参数量，剖切显示不等于已裁量。原始楼层、计量层归属和包围盒跨层候选也不代表完成几何分层。

工程设置绑定来源文档与 RVT 身份，支持原子存取。CSV 与当前范围、筛选和分组一致，保留身份、单位、缺失原因和工程修订。来源变化后旧结果标为过期，刷新前禁止当新结果使用。原生面积不是模板量或建筑面积，原生体积也不是可直接再扣洞口的毛量。

## 墙体计算口径与 1.8 增量范围

采用项目约定方法 **`BV.Wall.RectSolid/1`**，不宣称符合某地区规范。依据轴线长度、未连接高度和类型厚度构造矩形实体基准，对明确宿主关系的矩形 `Opening` 求墙局部平面内的并集并扣除；与实际墙实体作双向差集及体积一致性核验，通过后才生成结果与逐条台账。原生参数量单列，不参与重复扣减。

同阶段主模型墙体使用包围盒生成候选，再以实际实体交集检查正体积重叠；超限、缺证据或几何失败不默认为无交集。**未 join 的重复／重叠墙也不能当独立墙相加**。这个门槛只拒绝当前不可靠输入，不实现交接优先级或自动扣重。容差和检查状态随事实保留。

当前不支持弧墙、附着／顶部约束、显式交接、未核实门窗族切洞、任意异形轮廓、材料层、跨层切量、链接墙以及墙梁柱板交接增扣。门窗名义宽高不替代实际切洞。梁柱板、地区规则、模板量、正式计算书、查看器／云端重算及工程设置随 ZIP 传递均属后续任务。

### 单侧轴向投影面积

1.8 新面积方法标识为 **`BV.Wall.AxisProjection/1`**。对通过原有几何校验的墙，采用轴线长度 `L`、未连接高度 `H` 和矩形洞口并集 `U`：基准面积为 `L × H`，结果面积为 `L × H − U`，单位 m²；体积继续按 **`BV.Wall.RectSolid/1`** 计算，单位 m³。逐条台账分别保留带符号面积与体积变化，重叠洞口只计其并集新增部分。

投影面积不读取原生面积作为扣减基底，不从可见网格推算，不是墙面展开面积或带洞侧面的实际表面积。原生 Revit 面积／体积保留各自来源与状态，作为对照列，不要求与项目方法同口径，也不再次扣洞。

### 工程归属报表

新增代码模块 `CivilWallReport` 的模式标识为 **`BV.Wall.Report/2`**，目标是将同批原生记录、墙体事实与计算结果严格关联后，输出当前范围的分组、墙明细、原生量对照及逐条台账。来源文档、路径、修订、UniqueId 和 ElementId 不完整或不匹配时拒绝混合报表；不能只按名称或显示类型拼接。

分组范围包括计量层、整构件施工段、原生参照楼层与墙类型。工程设置沿用 `.bvproject.json` 的加载、保存及身份检查；仅改变报表归属，不切层、切段或参与几何扣减。同名但不同身份的组不应合并；未映射和未分配应单列。有效覆盖数、未支持、失败和原生量缺失／无效／读取失败分别保留，部分有效合计不能冒充全量结果。过滤、分组、CSV 与关联定位需使用同一完整来源集合，模型或工程方案变化后旧结果需失效或重新生成。

旧 `CivilWallCalculator.ToCsv` 的 **25 列墙汇总／11 列台账**兼容合同保留，不把新面积字段悄悄插入旧版列序。新版使用显式的 `BV.Wall.Report/2`，分组／墙明细／台账为 11／38／14 列，接收者应先识别模式和单位。本批后台覆盖领域、报表、读取替身与离屏 WPF；离屏窗口不显示，不等于真实 Revit 窗口流程验收。

领域、报表、读取适配、离屏 WPF、API 元数据编译、实际 SDK 与窗口点击分别验收。**以下是 1.7 历史证据：** Revit 2020，build `20190327_2315(x64)` 通过受限墙体 SDK 与独立数据核验，覆盖无洞口／单洞口／重叠矩形洞口以及非矩形／未 join 相交墙拒绝，详见 [1.7 验证范围](tests/host/REVIT2020_VALIDATION.md)。该记录不验证 1.8 新增面积、工程分组或新版 CSV；1.8 没有新增实机证据。其他年份／build、真实窗口、任意门窗族切洞与完整规则仍待分别验证。

## 模型导出选项

| 选项 | 实际内容与限制 |
|---|---|
| 几何和构件信息 | 所选非模板三维视图可见网格、实例／链接变换、参数、身份与楼层，固定启用 |
| 贴图纹理 | 能找到的本地 PNG／JPEG／WebP 颜色位图，缺失项有提示，不代表完整渲染外观 |
| 系统树 | 已访问文档的 MEP 系统，成员引用限于已导出构件 |
| 空间树 | 房间／空间及 Revit 已提供的归属，不猜测几何包含关系 |
| 专业树 | 项目类别映射，无法识别者保留 Other |
| CAD 几何 | 可见 CAD 网格，不包含原始 DWG 或完整二维曲线 |
| 轴网 | 名称和变换后的米制曲线采样数据 |
| 二维视图 | 用户明确选择的视图经 Revit 官方 DWG 接口导出并作为附件打包 |

新增树／轴网位于 `metadata/`，DWG 位于 `drawings/`。写出数据不代表查看器已具备所有对应界面；二维附件可以解压取得，实际显示能力见查看器说明。

长度使用米；实例／链接变换、镜像、法线和局部网格锚点保留。原始量快照的字段、身份、维度和缺失状态见 [QUANTITY_SNAPSHOT](QUANTITY_SNAPSHOT.md)。几何内容哈希去重、类型／族参数和有界实例参数缓存用于减少重复工作；没有同模型、同视图、同选项、同磁盘计时，不承诺速度倍数。

源大小表示主 RVT 最后保存版本，不含链接 RVT；云模型、未保存或不可读时明确不可用。ZIP 是所选显示内容与附加数据的交换包，**不是 RVT 无损压缩备份**，可能比主 RVT 更大。`exportStatistics` 记录 JSON、附件及未压缩字节；ZIP 最终大小在原子写包后统计。
