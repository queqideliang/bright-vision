# 崛亮视觉 · Bright Vision Revit 插件

当前社区源码版本 **1.7.0 开发预览**，采用 Apache-2.0；第三方组件保留各自许可。插件包含模型 ZIP 导出、土建原始量工作台、部分计量工程设置和首批墙体试算。它们由本项目源码实现，运行时使用 Autodesk Revit API 与 Windows/.NET 系统库，不需要其他导出引擎。安装包是否已交付、具体宿主 build 和业务验收结果以对应发行说明为准。

**完整土建规则算量尚未实现。** 首批墙体试算不是地区清单／定额、模板量或全部墙体算法。完整产品目标和各期验收门槛见 [功能分期](CIVIL_QUANTITY_ROADMAP.md)，合法本地引用及构建流程见 [BUILDING](BUILDING.md)。

## 在 Revit 中使用

通过 [独立安装器](../bright-revit-installer/README.md) 安装，保存工程并退出全部 Revit 后升级，重新启动生效。入口为 **BV → bright vision**，官方产品显示“崛亮视觉 · Bright Vision”。

- **本地导出模型 ZIP：** 编辑模型名、选择非模板三维视图、输出目录和导出内容。已有 ZIP 覆盖须确认；失败或取消不替换原包。完成后显示输出统计、耗时、源 RVT 和 ZIP 大小及体积变化。
- **土建原始量工作台：** 在 Revit 内按范围、类别、阶段／设计选项读取原生参数，筛选分组、定位构件和输出 CSV，无须先导出 ZIP。
- **工程设置：** 计量层映射、单一施工段归属和 `.bvproject.json` 存取，保留原楼层与解析来源；只改变报表归属，不切分几何或写回 RVT。
- **墙体试算与台账：** 为明确支持的普通直墙读取事实、核对几何、试算矩形开洞并集扣量、复核计算过程和导出 CSV。未支持或失败记录单列，不按零补齐。

接收者安装 [独立查看器](../bim-viewer/README.md) 后，无需安装 Revit 即可打开导出的 ZIP。查看器不能直接读取 RVT；插件本身必须在合法 Revit 宿主内执行。

## 原始量与工程设置

墙、结构梁、建筑柱、结构柱、板分别读取固定实例参数中的长度／面积／体积，保留参数来源、单位和状态。结构支撑不当梁；叠层墙、幕墙、嵌套族、未映射和未加载链接等保留明确覆盖与排除信息，不混入受支持合计。

当前选择／当前视图／当前工程首先限定根文档。阶段与设计选项明确显示；视图纳入构件时仍读取整构件参数量，剖切显示不等于已裁量。原始楼层、计量层归属和包围盒跨层候选也不代表完成几何分层。

工程设置绑定来源文档与 RVT 身份，支持原子存取。CSV 与当前范围、筛选和分组一致，保留身份、单位、缺失原因和工程修订。来源变化后旧结果标为过期，刷新前禁止当新结果使用。原生面积不是模板量或建筑面积，原生体积也不是可直接再扣洞口的毛量。

## 1.7 首批墙体试算的确切范围

采用项目约定方法 **`BV.Wall.RectSolid/1`**，不宣称符合某地区规范。依据轴线长度、未连接高度和类型厚度构造矩形实体基准，对明确宿主关系的矩形 `Opening` 求墙局部平面内的并集并扣除；与实际墙实体作双向差集及体积一致性核验，通过后才生成结果与逐条台账。原生参数量单列，不参与重复扣减。

同阶段主模型墙体使用包围盒生成候选，再以实际实体交集检查正体积重叠；超限、缺证据或几何失败不默认为无交集。**未 join 的重复／重叠墙也不能当独立墙相加**。这个门槛只拒绝当前不可靠输入，不实现交接优先级或自动扣重。容差和检查状态随事实保留。

当前不支持弧墙、附着／顶部约束、显式交接、未核实门窗族切洞、任意异形轮廓、材料层、跨层切量、链接墙以及墙梁柱板交接增扣。门窗名义宽高不替代实际切洞。梁柱板、地区规则、模板量、正式计算书、查看器／云端重算及工程设置随 ZIP 传递均属后续任务。

领域、读取适配、WPF、实际 SDK 与窗口点击分别验收。1.7 新墙体安全门槛的真实宿主测试在发行说明确认前标为**待验**；源码能编译或合成夹具通过不代表已在真实工程验证。

## 模型导出选项

| 选项 | 实际内容与限制 |
|---|---|
| 几何和构件信息 | 所选非模板三维视图可见网格、实例／链接变换、参数、身份与楼层，固定启用 |
| 贴图纹理 | 能找到的本地 PNG／JPEG／WebP 颜色位图，缺失项有提示，不代表完整渲染外观 |
| 系统树 | 已访问文档的 MEP 系统，成员引用限于已导出构件 |
| 空间树 | 房间／空间及 Revit 已提供的归属，不猜测几何包含关系 |
| 专业树 | 项目类别映射，无法识别者保留 Other |
| CAD 几何 | 可见 CAD 网格，不包含原始 DWG 或完整二维曲线 |
| 轴网 | 名称和变换后的米制曲线采样数据 |
| 二维视图 | 用户明确选择的视图经 Revit 官方 DWG 接口导出并作为附件打包 |

新增树／轴网位于 `metadata/`，DWG 位于 `drawings/`。写出数据不代表查看器已具备所有对应界面；二维附件可以解压取得，实际显示能力见查看器说明。

长度使用米；实例／链接变换、镜像、法线和局部网格锚点保留。原始量快照的字段、身份、维度和缺失状态见 [QUANTITY_SNAPSHOT](QUANTITY_SNAPSHOT.md)。几何内容哈希去重、类型／族参数和有界实例参数缓存用于减少重复工作；没有同模型、同视图、同选项、同磁盘计时，不承诺速度倍数。

源大小表示主 RVT 最后保存版本，不含链接 RVT；云模型、未保存或不可读时明确不可用。ZIP 是所选显示内容与附加数据的交换包，**不是 RVT 无损压缩备份**，可能比主 RVT 更大。`exportStatistics` 记录 JSON、附件及未压缩字节；ZIP 最终大小在原子写包后统计。

## 构建、验证与年份

先按 [BUILDING](BUILDING.md) 配置合法 API 及 Framework／WindowsDesktop 引用；仓库不分发 Autodesk DLL、原安装程序或官方／客户模型。以 `reference-paths.example.json` 为模板，不提交本机实际配置。

```powershell
.\Build-Exporter.ps1 -HostConfigPath .\local-references.json `
  -OutputPath .\artifacts\BV-1.7.0 -SkipFixture
```

完整目标为 Revit **2015—2026**，14 个年份／运行时变体：2015—2020 使用 net45，2021—2024 使用 net48，2025／2026 各有 net8 和 net10。2025-net10 基于对应 net8 API 契约，具体宿主仍待分别验证。现代运行时按宿主配置选择，不能只按年份猜测。构建清单保存源码、API 和输出 SHA；编译结束再次核对源码没有变化。

纯领域、读取器、离屏 WPF、API 元数据编译和真实宿主执行是不同证据层。例如 `tests/Test-CivilWallCalculation.ps1`、`tests/Test-CivilWallReader.ps1`、`tests/Test-CivilWallUi.ps1` 与 `tests/Test-CivilWallApi.ps1` 分别验证对应范围；当前单次真实墙体驱动见 [host 开发说明](tests/host/README.md)。测试数据使用合成夹具或开发者合法准备的专用副本，不将用户正在编辑的模型作为测试素材，不跳过安全／许可提示。

源码可构建不等于二进制逐字节可重现；安装完整包不等于所有年份、build 和功能均已实测。每次发行应列明版本、已测模型、支持边界、签名与限制。
