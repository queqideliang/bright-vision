# Bright Vision 土建计量：功能分期与验收

**版本范围说明：** 此公开源码包含 BV 1.11 的检查更新与功能介绍／使用指南入口；安装和功能入门见 [插件使用说明](USER_GUIDE.md)。下文 1.10、1.9、1.8 的本机部署、发布状态及实机证据保留其历史语境，不作为 1.11 当前线上状态或本版实机通过结论。本次发布情况以 [1.11 发行页](https://github.com/queqideliang/bright-vision/releases/tag/revit-v1.11.0) 为准。

产品目标是在 Revit 中提取可靠事实、组织计量范围、执行可复核计算，再由没有 Revit 的接收者通过独立查看器核查模型与结果。当前公开插件是 **BV 1.8.0 开发预览**，本机已部署 **1.10.0 墙体交接体积核算开发版**。第一期已有核心原始量能力，第二期只有部分工程设置；第三期按有限墙体、面积及工程报表、规则模板与真实矩形切洞、墙墙交接分批推进。**第三期尚未全部完成，也不是完整土建清单／定额算量系统。**

1.8 的后台、远程源码 CI、公开四附件下载与本机四年份 CLI 升级已分别核对，详见 [1.8 发行说明](https://github.com/queqideliang/bright-vision/releases/tag/revit-v1.8.0)。没有本版新实机 SDK／窗口证据；旧 1.7 的 SDK 只作历史，不能替代 1.8 验收。独立插件没有自动更新器，查看器 0.7 仍内置 1.7。源码能力见 [README](README.md)，构建见 [BUILDING](BUILDING.md)。

1.9 已完成限定 Revit 2020 SDK 的 120 项断言／8 场景和独立复核，保留其四年份历史部署。1.10 已独立完成同一 Revit 2020 build 的 340 项断言／10 场景及 83 份数据复核，并在本机 2017／2018／2020／2026 通过 CLI 升级，旧版 20 个文件已备份。前四轮夹具失败记录完整保留，分别涉及自动连接和异形反例的默认基准偏移；最终驱动明确拆开／重连、固定输入基准后重新验收，未放宽标准。1.9／1.10 尚未公开发布。精确状态见 1.9 开发记录（本机验证资料，不随源码公开）、1.10 开发记录（本机验证资料，不随源码公开）和对应验证索引。

## 第一期：原始量工作台

- **范围与身份：** 当前选择／当前视图／当前工程；首批根文档，保留文档、UniqueId、阶段、设计选项和排除项。视图纳入的是整构件参数，不将剖切显示当裁量。
- **量表：** 普通墙长度／面积／体积，结构梁长度／体积，建筑柱与结构柱体积，板面积／体积。支撑不当梁，父子／叠层／幕墙等特殊对象明确状态。
- **查询与检查：** 名称、类型、楼层和 ID 搜索，按类别／楼层分组，缺失／无效／读取失败／不适用分别显示。包围盒跨层只产生待核查候选。
- **联动与输出：** 重新核对来源身份后选择定位；当前过滤与 CSV 一致。模型修改后旧表过期，刷新前不冒充新结果；零值与缺失不混淆。

验收覆盖墙梁柱板、零值／缺参、特殊排除、空范围、选择定位、模型修改后刷新及真实窗口操作。已有 SDK 或合成数据证据不代替按钮和窗口的实际流程验证。

## 第二期：工程设置与模型准备

- **工程基础：** 单体、单位、坐标、模型版本、参与文档、阶段／设计选项和可复用范围，计算批次记录输入身份。
- **计量层与施工段：** 已有原楼层映射、计量层定义、整构件单段归属和汇总；后续补地下／地上、层高、跨层／跨段策略、重叠和未归属检查。几何切量与整构件归属分别标记。
- **类型映射：** 类别与结构用途到业务构件，未识别队列、人工修正及版本记录；关键字只能建议，不能无提示确定口径。
- **结构与附加属性：** 材料、尺寸、标高和规则所需事实，注明实例／类型／计算／人工来源、维度、校验及变更。
- **持久化与身份：** 本地工程方案与源文档绑定；副本、相同 ElementId 和链接重复放置不混淆。计算项目字段与写回 RVT 分开；后者须显式事务和撤销。
- **计量数据：** 逐步加入轮廓／实体、宿主／洞口关系、链接变换和覆盖状态，不能只保留显示三角网格。

验收要求保存重开一致，修正可追溯，跨层／跨段／链接／工程副本无静默重复和漏项。当前工程设置尚不嵌入模型 ZIP，也未与查看器／云端设置同步。

1.8 将已有计量层和单段归属用于墙体报表，仍不代表完整类型映射、几何切层／分段或第二期整体完成；映射只改变报表标签与归属，不改变面积／体积公式。

## 第三期：墙体计算闭环

1. **先分事实。** 原生净参数、项目方法的独立基准、洞口及交接证据分别保留。原生体积可能已扣洞口与连接，不能再作为毛量二次扣除。
2. **1.7 的有限方法。** `BV.Wall.RectSolid/1` 从普通直墙轴线、未连接高度和类型厚度构造矩形基准；明确矩形 Opening 在墙局部平面内求并集，再与实际实体双向差集和体积一致性核验，通过后生成台账。门窗名义尺寸不等于实际切洞。
3. **墙体重叠门槛。** 同阶段主模型墙体的包围盒只筛候选，实际实体正体积交集决定拒绝。未 join 的重复墙也不能独立相加；检查不完整、超限或几何失败都不默认为无重叠。这不是自动交接扣重，也不是链接／梁柱板交接算法。
4. **后续几何与规则。** 明确支持的门窗实际切洞、异形轮廓、交接优先级、重叠去重、跨层／分段和材料层逐项加入。原生参数模式、项目约定和地区清单／定额方案保留不同依据与版本。
5. **结果与运行。** 保留基准、每条增扣、关联构件、来源、单位、公式／几何依据、最终状态和批次；失败／取消不覆盖原完整结果，来源变化使旧结果过期。

6. **1.8 第二批。** 在原有几何门槛不变的前提下，增加 `BV.Wall.AxisProjection/1`：单侧轴向投影基准 `L × H` 减明确洞口并集 `U`，分别保留面积和体积的带符号台账。新增 `BV.Wall.Report/2` 完整来源关联、工程归属与类型分组、覆盖／缺失／失败统计、过滤和定位及新版 CSV。原生量只对照，不作为毛量再扣；旧体积 Rule/1 与旧 25／11 列 CSV 合同保留。

7. **1.9：默认模板与读取控制，本机已部署。** 默认采用 BV 自有“项目几何核对”；另保留“仅原生矩形 Opening”策略。两个方案支持复制、受限编辑、严格 JSON 导入导出和内容指纹，工程 Schema 2 保存规则，改变规则即要求重算。新增门窗实际矩形切洞分支通过宿主官方 `RevitAPIIFC` 可选 API 读取真实曲线，仍须整墙实体核验；没有接口、形状非矩形或证明失败时不按名义尺寸补算。计算、筛选／分组、CSV、定位和保存核对已封存事实、结果和规则，读取在明确操作边界支持进度与取消。限定 Revit 2020 SDK 120 项／8 场景及独立复核通过，不推广为所有年份、族或真实窗口验证。

8. **1.10：完整墙墙组件与顺序分配，本机已部署。** `BV.Wall.ComponentPriority/1` 读取同阶段主模型墙的实际相交及双向显式关联，纳入范围外邻墙，逐组件由用户明确确认顺序。每墙洞后实体依次减更高优先级墙，保留每步剩余量；证明组件并集形状、结果互不重叠及体积守恒。独立 `.bvwalljoins.json` 绑定完整依赖与几何身份，同几何重开只复用顺序，结果须重算。旧单墙 `reject-overlap` 不改；交接体积不除厚度当作新面积。安装包隔离检查、限定 Revit 2020 SDK 和四年份本机 CLI 升级分别通过；真实 Ribbon／窗口及其他年份功能仍须另验。

**完整第三期剩余清单不因本批缩减：** 墙墙组件在本批支持边界之外的端部增量及复杂连接，墙梁柱板完整依赖组件、明确优先级的交接增扣和重叠分配；任意轮廓／附着／约束墙的可靠几何基准；跨层／跨段几何切量与守恒；材料层和链接实例边界；人工核定的跨层、失败及容差算例，以及更多宿主和真实窗口验收。地区规则已由用户明确暂缓指定，先推进项目约定几何核对，不把第三方数据库直接当作 BV 可执行算法。

单侧轴向投影面积不是抹灰、模板、双面墙、外露表面或建筑面积。人工业务标准和首个地区条文尚未定义，不能把项目约定面积命名为地区量或正式业务净量。各版领域、报表、离屏界面、API 编译、隔离安装和真实宿主均分别列证据；本批通过 CLI 启动专用 Revit 样例，由 SDK 回调执行和回滚，不操作鼠标。

旧单墙方法继续排除显式交接；1.10 的独立组件方法只处理具备完整证明的交接。弧墙、附着／顶部约束、未知切洞、链接、梁柱板交接和地区扣减仍不在本批支持范围。**1.7 历史记录**中 Revit 2020 build `20190327_2315(x64)` 的三个矩形墙算例、非矩形与未 join 重叠墙拒绝、回滚及独立数据核验已通过，见 [验证范围](tests/host/REVIT2020_VALIDATION.md)；该记录不覆盖后续版的新功能。真实窗口和其他宿主仍须另验。后续每种规则都要有人工核定的单墙、洞口、多洞重叠、交接、跨层、失败及容差算例，逐条比较台账，不能只比较最终总量。

## 第四期：构件、计量项与规则覆盖

逐项支持普通／特殊构造，不能从一类小算例推广到全部几何。

| 类别 | 计划的主要计量项和场景 |
|---|---|
| 墙 | 材料层、叠层／幕墙专门处理、异形／斜墙、洞口、交接、跨层、面积／体积 |
| 梁柱板 | 建筑／结构分类、异形和斜构件、洞口、交接优先级、跨层／施工段 |
| 模板 | 接触／外露面、交接面和洞侧面及规则增扣，不把原生面积改名为模板量 |
| 建筑面积 | 独立计算边界、层高和空间条件、全计／半计／不计及规则版本，不用板面积总和替代 |
| 基础与土方 | 独立／条形／筏形基础、桩承台、垫层；原地形／设计边界、挖填和沟槽 |
| 楼梯／坡道 | 梯段、平台与台阶的投影／展开／实体量及归属 |
| 门窗／幕墙／零星 | 明确的数量、面积、长度及子构件去重，不按名称自动确定口径 |
| 屋面与装饰 | 楼地面、墙面、天棚、踢脚、防水／保温、材料层、展开／投影及洞口交接 |

规则方案计划支持查看、复制、修改、校验、版本锁定和重算。实物量、清单与定额不假定一一换算。首个地区／版本须由业务人员确认依据与算例后再实现；钢筋翻样、机电算量和商业计价是独立范围。

## 第五期：报表、表格算量与对比

- 工程／单体／计量层／施工段／材料／类别／类型汇总，构件与增扣明细，缺失／失败覆盖表。
- 计算书保留来源、输入、公式、规则版本、批次和复核状态，支持明确的 XLSX／PDF 输出及三维定位。
- 自定义计算行、变量、维度校验、模型量引用和人工补量，防循环引用和静默覆盖；人工量与模型量分列。
- CSV／XLSX 外部清单导入、编码／单位／计量项匹配，多对多与未匹配保留；量差区分几何、参数、映射和规则变化。
- 商业文件接口须按具体格式、合法样例与接口单独建设；不提供未完成却声称可用的按钮。

验收要求屏幕／文件的数值、精度、单位、范围和版本一致，任意结果可追到原始事实及规则，不同口径不静默相减。

## 第六期：效率、多端与 AI

- **增量计算：** 依据构件、宿主／交接依赖、映射与规则变化确定失效范围；先保证全量正确，再证明局部与全量结果一致。
- **源模型处理：** 按层／边界分割、属性写回、批量修正，先预览影响；事务、撤销和失败恢复单独验收，计量分段不强制破坏模型。
- **独立查看器：** 项目树、计量层／施工段、批次／规则、增扣关联和差异审查；补齐系统／空间／专业树、轴网及二维附件的接收界面。精确重算须具备足够数据和独立内核。
- **云端服务：** 模型／结果版本、成员权限、问题、审批、报告归档、离线冲突和审计；服务接口与开源社区能力明确分开。
- **AI 辅助：** 映射建议、缺参检查、自然语言查询、量差解释、规则草稿和报告整理；显示来源与人工确认状态，正式数量仍由可重算过程产生。
