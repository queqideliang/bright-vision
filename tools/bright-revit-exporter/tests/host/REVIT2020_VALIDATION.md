# Revit 2020：BV 1.7.0 墙体试算验证范围

2026-10-28，BV 1.7.0 的受限墙体 SDK 执行与独立数据核验通过。实测宿主为 **Revit 2020，build `20190327_2315(x64)`**，使用开发者本机合法安装的结构样例副本与可回滚夹具。生产插件与首发 1.7.0 构建字节一致；本次后续提交只更新测试工具和说明，不更换安装包或首发标签。

## 验证的计算范围

项目方法为 `BV.Wall.RectSolid/1`。独立定义一面长 10 m、高 3 m、厚 0.2 m 的普通直墙，几何上下文采用同阶段的明确三维视图：

| 算例 | 明确矩形 Opening 的并集面积 | 期望试算体积 |
|---|---:|---:|
| 无洞口 | 0 m² | 6 m³ |
| 一个洞口 | 2 m² | 5.6 m³ |
| 两个重叠洞口 | 3 m² | 5.4 m³ |

实际实体、独立并集计算、基准／扣减／结果、逐条台账及 CSV 在明确容差内一致。Revit 原生参数量单列，没有将已扣洞口的原生体积再当毛量扣除。

非矩形墙轮廓被拒绝。另建一面未使用几何或端点 join、却有正体积交集的墙，实际独立交集约 2.7 m³；读取器识别并拒绝该重叠输入，不将它当另一面独立墙相加。任意门窗族真实切洞没有在此样例中验证；受控未知切洞与无效证明的拒绝测试仅属于领域负例。

## 快照、回滚与证据门槛

- 读取前、墙体事实读取后、计算后三阶段保留原始 JSON，并比较对象键、标量类型和值、数组顺序。本轮三例的三阶段原始字节也分别完全一致。
- C# 结构比较忽略 JSON 对象键的排列，保留字段、类型、数值与数组差异，失败时记录首个差异路径；独立 Node 再检查三阶段数据与计算输入相同。
- 最终报告必须为 PASS，终态必须为 `completed`，且 runId、启动／结束／终态时间与来源、驱动、辅助源码、插件及构建散列一致。缺失或过期状态不能代替通过。
- 重叠拒绝算例先检查有限非负差集、有限正容差及上限、独立已知体积；缺失／null 证明不能借助 JavaScript 比较规则通过。
- SDK 断言 81 项通过，Node 核验 28 份数据／CSV 证据。临时 TransactionGroup 已回滚，创建构件已移除；全部实例及类型计数前后均为 12,500，源文件 SHA、选择、视图和修改标记保持一致，没有保存源模型。

本轮新增证据不能追溯解释更早运行中未保留三阶段数据的文本比较失败。

## 可以自行运行的源测试

从源码仓库根目录执行纯 Node 回归，不需要 Revit、厂商 DLL、真实模型或访问网络：

```sh
node --test tools/bright-revit-exporter/tests/civil-wall-host-verifier.test.mjs
```

当前 33 个合成正反例覆盖量值、台账、快照差异、终态及缺失几何证明。Windows PowerShell 5.1 中的 `Test-CivilSnapshotComparison.ps1` 另提供 50 条纯领域 DLL 比较器断言，默认使用系统 .NET Framework，无需 Revit 或私有引用缓存；可用 `-FrameworkDirectory` 指定其他合法本地引用目录。源 CI 分别运行这两项测试。真实 SDK 的构建、单次注册、启动与精确清理见 [开发验收说明](README.md)；开发者须自行合法准备 API 和样例。
