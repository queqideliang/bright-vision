# BV 自有墙体规则模板

版权 2026 崛亮视觉（Bright Vision），Apache-2.0。

本目录是 BV 1.9 开发版的可导入示例。正式已发布的 1.8 插件没有模板选择器；这些文件不能使旧程序获得新算法。模板内容与生产 `CivilWallRuleTemplates.Catalog()` 一致，`index.json` 记录内容指纹和文件 SHA-256。

| 文件 | 适用范围 |
|---|---|
| `project-geometry.bvwallrules.json` | 默认“BV 项目几何核对”：矩形参数基准，明确原生 Opening，以及由官方 API 读取、形状和整墙实体均获核验的矩形门窗切洞 |
| `native-opening-only.bvwallrules.json` | “BV 原生矩形 Opening 核对”：仅接受明确的原生矩形 Opening；不纳入门窗族切洞 |

在墙体工作台选择内置模板，或使用“导入 BV 规则 JSON”。“编辑自有模板”会复制内置模板并生成独立标识；修改自有模板会增加修订号。可编辑名称、说明、已有切洞策略和允许范围内的几何容差。体积与面积算法不能通过输入文字、脚本或未知方法名扩展。切换规则后必须重算，工程 Schema 2 和 CSV 会保留所用规则的标识、修订及指纹。

两个模板均为项目几何核对口径，不是全国或任何省份的清单、定额、抹灰、模板或建筑面积规则。墙体交接仍采取拒绝重叠；配置文件中的空优先级集合不代表已实现交接分配。名义门窗宽高不能替代真实切洞，缺少宿主官方 `RevitAPIIFC.dll` 或几何证明时保留未支持原因。BV 不分发该 Autodesk 程序集。

本目录不含其他厂商的数据库、规则正文或模板。`.pmdb`、其他厂商的计算规则 XML 和计算书 DOCX 不能作为 BV 规则 JSON 导入。具体地区、标准年份与计量项经确认后，须另行实现算法并用人工核定算例验收，不能通过改模板名称获得地区符合性。
